> **LINUX-WEB.sh** — An interactive website built with Vue 3 and Vite to introduce the world of Linux in a visual, modern, and user-friendly way.

## 📖 Description

LINUX-WEB.sh is a frontend project designed to serve as a starting point for those who want to learn **what Linux is**, its most popular distributions, open source philosophy, basic commands, and why it is so important in the world of technology.

Ideal for:

- Linux Enthusiasts 🐧
- Computer Science Students 💻
- Technical Content Creators 🎥
- Anyone who wants to showcase Linux in an engaging way 🌟

## 🚀 Technologies Used

- [Vue 3](https://vuejs.org/) - Composition API
- [Vite](https://vitejs.dev/) - Ultra-fast Bundler
- [Vue Router](https://router.vuejs.org/) - For SPA navigation
- [Tailwind CSS](https://tailwindcss.com/) *(optional, if you use it)* or pure CSS
- [AOS](https://michalsnik.github.io/aos/) *(optional)* - Scrolling animations
